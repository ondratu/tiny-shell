# Download

tiny-shell is released as source code. There are no binary packages yet.

## Releases

Releases will be published on the
[releases page](https://github.com/ondratu/tiny-shell/releases) of the project
on GitHub, with the source archive and, later, the binaries of the programs.
Until the first release, take the current source from the repository:

```sh
git clone https://github.com/ondratu/tiny-shell.git
cd tiny-shell
make
```

See [Installation](install.md) for the requirements and for `make install`.

## Packages

None yet. `make install PREFIX=/usr DESTDIR=...` is made for packagers, and the
[installation page](install.md) lists what it installs.
